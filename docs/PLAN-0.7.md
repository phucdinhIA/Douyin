# 0.7 — investigation and implementation plan

Scope: Douyin 40.6.0 / build 406019, iPhone 15 / iOS 18.5. Original IPA is preserved. This is a test candidate, not a claim that physical-device failures are resolved.

1. **Separate working and failing paths.** The 0.6 device report has successful `AWEFeedTableViewController` initial/load-more callbacks; the separate `AWEDCFeedListViewModel` path has five -4 and nine -11001 errors. Search/comment callbacks were not observed in that session. Neither login nor damaged IPA is established as the cause.
2. **Trace error construction.** Static inspection finds `AWEJSONResponseSerializer responseObjectForResponse:jsonObj:responseError:resultError:` at `0x12b11b84`. Its `com.aweme.network.error` -11001 branches describe invalid input or failure to convert data to a dictionary. This meaning applies only after matching the domain. Add a bounded observer preserving return/error pointers, reporting input type, HTTP status, fixed MIME category and known error category. Never log response body, URL, keyword, cookies, raw headers or unknown domain. Do not replace errors with success or change transport formats without evidence.
3. **Activate the local background component.** In 0.6, switchState was read but module entry/decision hooks were not called. The class getter `AWEFeedBGPlaySettings enableBGPlayComponent` reads the cached `syncGetAWEFeedBGPlayComponent` experiment; native module setup/notification handling consults it. Overlay that component configuration when Background audio is ON, calling the original once. Keep native content eligibility, explicit pause, interruption/PiP and playback lifecycle intact. Observe actual player decisions and lifecycle to distinguish configuration, eligibility and interruption failures. Device success is still unverified.
4. **Remove the manifest restriction on landscape.** Original iPhone `UISupportedInterfaceOrientations` contains Portrait only; the original native landscape controller supports landscape masks. Add LandscapeLeft/Right to the main app manifest, preserving iPad/extension orientation and all background modes. Keep native controller/delegate rotation policy. This enables native full-screen rotation requests; it does not force every feed screen to rotate or override iOS orientation lock.
5. **Provide a practical public-profile entry.** Add menu actions to search a creator name on Bing with a Douyin /user/ site query and open an official HTTPS public profile link. Encode Unicode/reserved query characters, reject invalid/oversized input and untrusted URL hosts/schemes/credentials/paths. Strip tracking query from profile links. User-triggered browser opening only; no query logging, account impersonation or cookies collected. This is web discovery, not unlimited native search. Actual results/playability depend on public indexing and Douyin guest availability.
6. **Review compatible open source.** Reviewed pinned DYYY source and two Android LSPosed/Xposed projects; see [research](RESEARCH-0.7.md). No third-party binary is executed or incorporated. Android Java/Dex hooks are not iOS ObjC hooks. No verified native guest-search-unlimited solution was found in the reviewed sources.
7. **Validate, then package.** Run packaging, Foundation ABI/forwarding/error-pointer/privacy/input-boundary regressions and UIKit iPhone 15 fixture. Review fixture images. Build arm64 with warnings as errors; verify artifact provenance/signature/dependencies, source hash and independently compare IPA entries/audited hashes. Preserve all previous candidates.
8. **One physical-device acceptance round.** With Portrait Orientation Lock OFF: play a horizontal video and use its native Full screen button, test both rotations and returning to portrait. Background audio ON: start a normal video, lock 30 seconds, unlock; repeat after manually pausing, then test interruptions. Test Featured/Tips Retry separately, native Search, public web finder and profile viewing, comment thumbnails and LIVE. Copy diagnostics afterward. No simulator fixture can establish Douyin server behavior or real lock-screen audio.

Rollback: keep the signed previous version and original IPA. No migration or native preference write is introduced. Turn Background audio OFF and restart to restore the original component/getter decisions. Do not uninstall the app if its data needs preserving.
