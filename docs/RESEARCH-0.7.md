# Research evidence for 0.7

Retrieved 2026-10-02 by HTTPS; reviewed as untrusted source material. Original app/mod code was never executed. No copied implementation or binary is shipped.

- [Apple UISupportedInterfaceOrientations](https://developer.apple.com/documentation/bundleresources/information-property-list/uisupportedinterfaceorientations): orientation availability is declared in the bundle. DocC JSON SHA-256 `429b4020a97dd0436510480b338a979c8df1af50322859a3e75edc36b369dd3c`.
- [Apple UIViewController supportedInterfaceOrientations](https://developer.apple.com/documentation/uikit/uiviewcontroller/supportedinterfaceorientations): controller and app policies constrain rotation; updating the manifest alone does not guarantee every controller rotates. DocC JSON SHA-256 `48dbc42b915a985186b8deba184c867b10b648fb6a7e01bed88d38d944f96d08`.
- [DYYY pinned source](https://github.com/huami1314/DYYY/blob/6c3dfbd911822b4d0f758f184c196566e8142291/DYYY.xm), SHA-256 `6f005f7903bf315947662ea478136db0db6a21e7dd2d53a426491d10fc94408a`: its listenVideoStatus rewrite changes per-content state. Not adopted; a local component setting is narrower. Comment-image saving URL choices do not prove a thumbnail loading fix.
- [DouyinEnhancer](https://github.com/twyora/DouyinEnhancer/tree/2f41dbde5f1043ab7b93cc54552586c06f4d3eb9): reviewed README, hooks and `ListenAwemeFilterHooker.kt`. Uses Xposed/YukiHookAPI, feed filtering and local playback/UI changes. README lists overriding listen-mode copyright restrictions; not adopted. The reviewed files do not establish unlimited unauthenticated server search. README SHA-256 `8d09fb701bd768da88cf5fcb527558ad5416acaceb362f645994f2964bc6ef03`.
- [douyim](https://github.com/1zzzzzlll/douyim/tree/1f662082493f909dcf121a9681aac1574a97421a): reviewed README, player state tracking, filtering and touch/UI lifecycle. Java player hooks call the original and track play/pause/completion; useful as a lifecycle design reference, not an iOS implementation or proof of full guest access. README SHA-256 `e01641080c7d9078d036b2f0596b788f9db0f7f45f9c43030e79f1c7f7bba6d1`.
- Public Bing query returned HTTP 200, but the retrieved results did not substantiate usable Douyin creator matches. Therefore the menu action is described strictly as opening a web search, with no assertion that all profiles/videos are indexed or playable as a guest. Official profile URLs are validated locally; no native internal routing is guessed.

Static analysis is version-specific. The original IPA has a Portrait-only iPhone manifest and native `AWELandscapeFeedViewController supportedInterfaceOrientations` at `0x15daedf8`. The background experiment initializer is at `0x12ea57fc`; `enableBGPlayComponent` is at `0x12ea8118`. The JSON response error builder described in the plan is at `0x12b11b84`. These are client facts; the actual device response and error domain remain to be observed.
